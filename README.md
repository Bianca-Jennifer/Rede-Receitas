# Rede-Receitas

## Status do Projeto
Em desenvolvimento.

## Sobre
O **Rede-Receitas** é um projeto de estudo desenvolvido com o framework **Laravel**, com foco na construção de uma aplicação web para compartilhamento de receitas.

O projeto não está finalizado e não tem como objetivo o uso em produção. Ele evolui conforme o aprendizado e a implementação gradual de funcionalidades.

## Descrição
A aplicação tem como finalidade permitir que:

- Usuários realizem cadastro e autenticação
- Usuários cadastrados publiquem receitas
- Usuários visualizem receitas publicadas por outros usuários
- Usuários salvem receitas para acesso posterior

Atualmente, o projeto já possui **entidades (models) e migrations criadas**, estabelecendo a base da estrutura do sistema e do banco de dados.

## Estrutura Atual do Projeto
No estado atual, o projeto conta com:

- Models definidos
- Migrations para criação das tabelas
- Configuração inicial do Laravel
- Templates Blade
- Estrutura inicial do back-end
- Página de exibição de receitas filtradas implementada
- Página de detalhes da receita implementada

Algumas funcionalidades ainda estão em fase de implementação ou refinamento.
